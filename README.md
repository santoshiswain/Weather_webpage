#  Weather App

This is a simple Weather App that shows real-time weather information for any city.  
Users can search for a location and get details like temperature, humidity, and weather conditions.

---

#  Features

- Search weather by city name
- Shows temperature, humidity
- Fast and user-friendly interface
- Give 5 day forecast
---

# Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeather API (or any weather API you used)
